# SQL-Music-Store-Analysis
## Project Overview
This project involves querying a relational database (Music Store dataset) to answer key business questions regarding customer spending, regional sales, and genre popularity.

## Technical Stack
*   **Language:** SQL (PostgreSQL / SQLite)
*   **Concepts Covered:** `JOIN`s, `GROUP BY`, Aggregate Functions (`SUM`, `AVG`, `COUNT`), and Subqueries.
